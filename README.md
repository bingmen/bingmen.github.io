## 📁 项目

### 📦 Bing 每日壁纸 - UHD 中文

**JSON + UHD + 缩略图 + 表格归档**

自动抓取 Bing 每日壁纸（中国地区），存储 UHD 和 320×240 格式，后者作为缩略图形成归档汇总表格。

🔗 [github.com/bingmen/bing-UHD-cn](https://github.com/bingmen/bing-UHD-cn)
